================================================================================
                         WHAT WILL HAPPEN
================================================================================

1. Script loads your trained PointNet++ model
2. Reads the raw LAS file (any size)
3. Processes in batches (GPU accelerated)
4. Classifies every point into 5 categories:
   - Road (0)
   - Snow (1)
   - Vehicle (2)
   - Vegetation (3)
   - Others (4)
5. Saves new LAS file with classifications

================================================================================
                      EXPECTED PERFORMANCE
================================================================================

Speed:        ~10,000-15,000 points/second (with GPU)
Accuracy:     93-95% (on similar data)
Memory:       Handles files of any size (processes in batches)

Example:
  500,000 points  → ~30-50 seconds
  1,000,000 points → ~1-2 minutes
  5,000,000 points → ~5-8 minutes

================================================================================
                       ADVANCED OPTIONS
================================================================================

Custom model checkpoint:
    python auto_label_las.py -i input.las -o output.las -m path/to/model.pth

Smaller batch size (if memory error):
    python auto_label_las.py -i input.las -o output.las -b 4096

Use CPU instead of GPU:
    python auto_label_las.py -i input.las -o output.las -d cpu

Get help:
    python auto_label_las.py --help

================================================================================
                      VIEWING RESULTS
================================================================================

1. Open labeled LAS file in CloudCompare
2. Go to: Edit > Scalar Fields > Classification
3. Points will be color-coded by class

Class IDs:
  0 = Road
  1 = Snow
  2 = Vehicle
  3 = Vegetation
  4 = Others
